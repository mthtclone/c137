What it is

This project aims to develop a short atmospheric walking simulator with an estimated playtime of 20–30 minutes.

The project is early: a custom engine layer, a first test level, and a growing set of environment assets.

Running it locally

  1. Create and activate a virtual environment with venv.

  2. Install dependencies from requirements.txt.

  3. Install the pre-commit hooks.

  4. Use the project Makefile to run, lint, and format.

$ python -m venv venv

$ source venv/Script/activate

$ pip install -r requirements.txt

$ pre-commit install

# then, day to day

$ make run // start the game

$ make lint // ruff checks

$ make format // black formatter
